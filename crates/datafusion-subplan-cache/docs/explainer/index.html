Whole results
  • Aggregates, joins, windows and DISTINCTs
  • Reused under a different ORDER BY, HAVING or LIMIT
  • Saved only if every partition finishes

    
Per-segment states
  • An aggregate over one file table
  • Optionally inner- or semi-joined to static tables
  • Needs a two-stage plan and an adapter that can scan a subset of files

    
Never cached
  • random() and correlated subqueries
  • Unregistered tables (policy Skip, Error or AssumeStatic)
  • Edge files of a lifted filter
